# UltrasharpTools MCP Server

**Ultra-fast MCP server enabling AI agents to comprehensively work with C# solutions: instant structural search, code modification with automatic linting/formatting/fixes, static debugging and backwards crash analysis, integrated Git automation.**

---

## 🚨 CRITICAL: Proactive MCP Tools Usage

**When working with C# code in this project, use SharpTools MCP FIRST, not as last resort.**

### Quick Decision Tree:

```
ANY C# task? → Use MCP tools IMMEDIATELY
├─ Understanding code? → LoadSolution + LoadProject (30 sec vs 30 min)
├─ Don't know exact class name? → FindPotentialDuplicates (semantic search!)
├─ Need to modify? → OverwriteMember (auto-linting included!)
├─ Debugging crash? → trace_backwards + AnalyzeLogs (15 sec vs 30 min)
└─ Code quality? → format_code + AnalyzeCodeStyle + apply_code_fixes
```

### Key Rules:
1. ✅ **ALWAYS** start with `load_solution`
2. ✅ **USE semantic search** when you don't know FQN: `find_duplicates`
3. ✅ **DON'T read manually** what MCP can do in seconds (10-100x faster)
4. ✅ **TRUST auto-linting** - every modification includes quality checks
5. ✅ **5 log formats** supported: ECS/JSON, Logcat, WebServer, XML, PlainText

## 🎯 Назначение проекта

UltrasharpTools — это production-ready MCP сервер для работы с C# кодовыми базами через Roslyn. Предоставляет AI-агентам инструменты для анализа, модификации и отладки C# решений на уровне IDE.

**Ключевые возможности:**
- ✅ **FastSymbolIndex** — 5-300x ускорение поиска символов (355K+ символов индексируются за 21.7s)
- ✅ **36 MCP инструментов** — анализ, модификация, отладка, качество кода
- ✅ **Git автоматизация** — автоматическое создание веток, коммитов, undo операций
- ✅ **Quality Tools** — CSharpier, Roslyn analyzers, auto-fixes
- ✅ **Advanced Tracing** — статический анализ потока выполнения, backtrace с Z3 SMT solver
- ✅ **Semantic Merge** — умное 3-way слияние с обнаружением переименований и перемещений

## 🏗️ Архитектура индексации

### Текущая (Phase 3) — FastSymbolIndex

**Многослойная система для O(1) поиска:**
```
Layer 1: Bloom Filter → Quick rejection (99% non-existent symbols filtered)
Layer 2: Flags Check → Metadata filtering (public/private, class/interface)
Layer 3: FrozenDictionary → O(1) lookup by name
Layer 4: Bitwise Filtering → Final filtering by flags
```

**Performance:** 10-100x ускорение, O(1) вместо O(N)

### Planned (Phase 6) — Incremental Indexing

**Delta-based architecture:**
- Layer 0: Base immutable index
- Layer 1: Incremental delta (mutable, recent changes)

**Performance:** 66-330x ускорение при модификации (33s → 0.1-0.5s)

### Planned (Phase 7) — Layered Multi-Branch

**Three-layer architecture:**
```
Layer 0: Base (main, committed, shared) ~600 MB
Layer 1: Branch Delta (per-branch, shared) ~10-50 MB
Layer 2: Working Directory (per-client, uncommitted) ~1-10 MB
```

**Performance:** 660-3300x ускорение переключения веток, 88% экономия памяти

## 🛠️ Команды разработки

### Сборка и публикация

**Droid (оптимизированная сборка):**
```bash
# Windows
publish-droid.cmd

# Linux/macOS
pwsh Dev.Scripts/publish-mcp.ps1
```

Особенности сборки:
- ✅ ReadyToRun (R2R) для быстрого старта
- ✅ Dynamic PGO для runtime оптимизаций
- ✅ Автоматическое удаление PDB файлов (~34 MB экономии)
- ✅ Удаление BuildHost директорий
- ✅ Организация в Scripts/ и Config/ папки
- 📦 Результат: `Run.Publish/Droid/` (~103 MB)

**Обычная сборка для разработки:**
```bash
dotnet build UltrasharpTools.sln
dotnet build UltrasharpTools.sln -c Release
```

### Запуск серверов

**SSE Server (HTTP):**
```bash
cd UltrasharpTools.Overlord
dotnet run -- --port 3001 --log-level Information
```

**Stdio Server:**
```bash
cd UltrasharpTools.Droid
dotnet run -- --log-directory ./logs --log-level Information
```

### Semantic Embedding

**Первая настройка:**
```bash
# Windows (двойной клик)
setup-semantic-embedding.cmd

# Linux/macOS
pwsh Dev.Scripts/setup-semantic-embedding.ps1
```

**Валидация конфигурации:**
```bash
# Windows
validate-semantic-config.cmd

# Linux/macOS
pwsh Dev.Scripts/validate-semantic-config.ps1
```

**Запуск TEI сервера:**
```bash
pwsh Dev.Scripts/setup-tei.ps1    # Windows
./Dev.Scripts/setup-tei.sh        # Linux
```

### Опции командной строки
- `--log-level <level>` — Verbose, Debug, Information, Warning, Error, Fatal
- `--load-solution <path>` — путь к .sln для загрузки при старте
- `--build-configuration <config>` — Debug/Release
- `--disable-git` — отключить Git интеграцию
